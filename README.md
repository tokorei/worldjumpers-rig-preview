# Worldjumpers robot rig preview

Temporary mobile review of the experimental Infinity robot rig. Open the GitHub Pages site for walk, run, stop, aim and shooting samples.

These are browser motion studies, not captured Unreal or PICO gameplay. Fingers remain open; the blaster is a review proxy.

Only the selected preview, required textures and Three.js runtime are included. Original gallery sources are maintained separately and read-only.
